در این نوشته یک مثال ساده از کد JavaScript می‌بینید:

```javascript
function greet(name) {
  const message = `سلام، ${name}!`;
  console.log(message);
  return message;
}

greet("دنیا");
```

و یک نمونهٔ دیگر به زبان `bash`:

```bash
# ساخت خروجی استاتیک
npm run build

# پیش‌نمایش محلی
npm run preview
```

### فهرست مرتب

1. فایل مارک‌داون را در پوشهٔ `/posts` بسازید.
2. فرانت‌متر YAML را کامل کنید.
3. دستور ساخت را اجرا کنید.
