توی این نوشته چند دستور کاربردی Git رو بررسی می‌کنیم.

### ۱. شروع کار با Git

اول از همه باید وارد پوشه پروژه بشی و Git رو فعال کنی:

```bash
git init
```

حالا پروژه‌ات آماده استفاده از Git هست.

### ۲. بررسی تغییرات

برای مشاهده فایل‌هایی که تغییر کردن از دستور زیر استفاده کن:

```bash
git status
```

این دستور بهت نشون می‌ده کدوم فایل‌ها جدید هستن، تغییر کردن یا هنوز به Git اضافه نشدن.

### ۳. ثبت تغییرات

برای اضافه کردن فایل‌ها به مرحله آماده‌سازی:

```bash
git add .
```

حالا می‌تونی تغییرات رو ثبت کنی:

```bash
git commit -m "Initial commit"
```

بهتره برای هر Commit یک پیام کوتاه و مشخص بنویسی تا بعداً راحت‌تر متوجه تغییرات بشی.

### ۴. اتصال به GitHub

اگر می‌خوای پروژه‌ات رو روی GitHub ذخیره کنی، ابتدا یک Repository بساز و بعد آدرسش رو به پروژه اضافه کن:

```bash
git remote add origin https://github.com/USERNAME/REPOSITORY.git
```

برای ارسال تغییرات:

```bash
git push -u origin main
```

### ۵. دریافت آخرین تغییرات

اگر روی پروژه چند نفر کار می‌کنن، ممکنه تغییرات جدیدی روی مخزن ثبت شده باشه.

برای دریافت اون‌ها:

```bash
git pull
```

### چند نکته مهم

- قبل از شروع کار، تغییرات جدید رو دریافت کن.
- برای هر تغییر مهم یک Commit جداگانه بساز.
- پیام Commit رو واضح و قابل فهم بنویس.
- قبل از اجرای دستورهای مربوط به حذف یا بازنویسی تاریخچه Git، مطمئن شو که می‌دونی چه اتفاقی می‌افته.
