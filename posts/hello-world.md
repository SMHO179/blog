## چرا وبلاگ؟

می‌خوام مطالبی که یاد می‌گیرم رو ثبت کنم و شاید بتونم به بقیه هم کمک کنم.

## ابزارهای استفاده‌شده

- Markdown برای نوشتن مطالب
- HTML و CSS برای طراحی
- Vercel برای میزبانی

## برنامه‌های آینده

قراره بیشتر درباره برنامه‌نویسی، پایتون، Go، لینوکس و پروژه‌های شخصی بنویسم.
