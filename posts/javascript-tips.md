این‌ها ترفندهایی نیستند که هر روز لازم شوند؛ اما وقتی لازم می‌شوند، ارزش این را دارند که از حافظه بگذرند و یادداشت شوند.

## تبدیل امن اعداد

همیشه پایه (radix) را مشخص کنید و به `parseInt` بدون پایه اعتماد نکنید:

```js
const page = Number.parseInt(raw, 10);

if (Number.isNaN(page)) {
  throw new Error("شماره‌ی صفحه نامعتبر است");
}
```

## مرتب‌سازی عددی آرایه

```js
// مرتب‌سازی پیش‌فرض رشته‌ای است؛ برای اعداد حتماً مقایسه‌کننده بدهید
scores.sort((a, b) => a - b);
```

## کپی سطحی آبجکت

```js
const settings = { theme: "dark", fontSize: 16 };
const patched = { ...settings, fontSize: 17 };
```

کپی **سطحی** است؛ آبجکت‌های تودرتو همچنان مشترک‌اند. برای کپی عمیق:

```js
const deepCopy = structuredClone(settings);
```

## کار با لیست‌های تودرتو

وقتی داده در چند لایه پیچیده می‌شود، جست‌وجو را به چند مرحله‌ی ساده بشکنید:

1. هر نوشته را با `filter` باز نویسی کنید تا فقط نوشته‌های منتشرشده بمانند.
2. با `flatMap` برچسب‌های همه‌ی نوشته‌ها را در یک آرایه جمع کنید.
   - برچسب‌های تکراری را با `Set` حذف کنید.
   - سپس مرتب‌سازی کنید.
3. در پایان با `map` به قالب نهایی برسانید.

```js
const uniqueTags = [...new Set(posts.flatMap((post) => post.tags))];
```

---

چند یادآوری پایانی:

- `??` فقط برای `null` و `undefined` است، نه `0` و رشته‌ی خالی.
- `?.` زنجیره‌ی طولانی متدها را امن می‌کند، ولی خطاها را پنهان هم می‌کند؛ زیاده‌روی نکنید.
- برای تاریخ‌ها، خودتان تبدیل ننویسید؛ [`Intl.DateTimeFormat`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat) کار را انجام می‌دهد.
